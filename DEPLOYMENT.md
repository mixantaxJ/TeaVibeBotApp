# RAG Telegram Bot - Руководство по запуску и развертыванию

Данное руководство описывает шаги по настройке, локальному тестированию и развертыванию RAG-бота на сервере.

## 1. Предварительные требования

Для запуска проекта локально или на сервере вам потребуются:
- **Docker** (Docker Desktop или Docker Engine)
- **Docker Compose** (обычно поставляется вместе с Docker)
- **Git**

## 2. Настройка окружения

Бот использует переменные окружения для хранения секретов.

1. Скопируйте шаблон `.env.example` в новый файл `.env`:
   ```bash
   cp .env.example .env
   ```

2. Откройте `.env` и заполните данные:
   ```env
   # Токен бота от @BotFather
   BOT_TOKEN=1234567890:AAH...

   # API ключ от DeepSeek
   DEEPSEEK_API_KEY=sk-your-key

   # Ваш Telegram ID для прав администратора (добавление в базу)
   ADMIN_IDS=[123456789]
   ```

## 3. Локальный запуск (через Docker Compose)

В корневой директории проекта выполните команду:
```bash
docker compose up -d --build
```

**Особенности первого запуска:**
- Установка тяжелых зависимостей (например, `fastembed`) может занять 2-5 минут.
- При первом старте Qdrant скачает языковую модель `multilingual-e5-small`.
- Посмотреть логи процесса можно командой:
  ```bash
  docker compose logs -f bot
  ```

## 4. Как тестировать бота

**Роль Администратора (Добавление знаний):**
1. В Telegram отправьте боту команду `/add`.
2. Бот попросит отправить текст. Отправьте фактологическую информацию.
3. Текст будет векторизован (FastEmbed) и сохранен в локальную базу Qdrant.

**Роль Пользователя (Поиск RAG):**
1. Отправьте боту любой вопрос, связанный с добавленной информацией.
2. Бот найдет релевантный контекст в Qdrant и передаст его в DeepSeek.
3. DeepSeek сформирует ответ на основе контекста.

## 5. Развертывание на сервере (Production)

Шаги аналогичны локальному запуску:
1. Подключитесь к VPS/VDS по SSH.
2. Установите Docker и Git.
3. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your-repo/rag-telegram-bot.git
   cd rag-telegram-bot
   ```
4. Создайте и заполните `.env` (как в шаге 2).
5. Запустите контейнеры:
   ```bash
   docker compose up -d --build
   ```

Бот будет работать в фоновом режиме. Файлы базы данных Qdrant и Redis сохраняются в томах (volumes), поэтому данные не пропадут при перезапуске сервера.
