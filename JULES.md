Фаза ORIENT и DISCOVER: Перед началом модификации кода агент обязан проинспектировать текущие зависимости и подтвердить наличие aiogram мажорной версии 3. Любые попытки сгенерировать код с использованием синтаксиса aiogram 2.x (например, Dispatcher.register_message_handler) должны быть пресечены.

Универсальные политики автономии (Universal Autonomous Agent Policies): Агенту запрещено хардкодить API-ключи, пароли администраторов или токены Telegram в исходном коде. Все секреты должны извлекаться из конфигурационного класса Pydantic.

Архитектурные ограничения RAG: Векторизация выполняется исключительно через локальную библиотеку fastembed. Запрещается внедрение внешних вызовов к API OpenAI Embeddings, так как это увеличит финансовые затраты на проект. Сохранение векторов происходит в локальную файловую систему через qdrant-client.

Управление LLM: Взаимодействие с языковой моделью строго зафиксировано на эндпоинте https://api.deepseek.com с использованием модели deepseek-v4-flash. Агент обязан реализовать модуль обработки RateLimitError (ошибка 429) с применением алгоритма экспоненциальной задержки (Exponential Backoff with Jitter) перед вызовом генерации ответа.

Безопасность FSM: Все хранилища состояний должны инициализироваться как RedisStorage. MemoryStorage признается неприемлемым (Not Applicable) для данного репозитория и должен быть удален, если обнаружен.
